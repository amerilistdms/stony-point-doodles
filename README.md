# Stony Point Doodles

Static HTML site for Netlify.

**Stony Point Doodles**  
*Healthy Puppies. Loving Homes. Lifelong Friends.*

## Structure

- `*.html` — pages
- `assets/` — CSS, JS, images
- `netlify.toml` — publish config

## Netlify

1. Import GitHub repo `amerilistdms/stony-point-doodles`
2. Branch: `main`
3. Publish directory: `.`
4. Deploy
