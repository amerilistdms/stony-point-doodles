# Stony Point Doodles — WordPress + ACF

Sitio familiar, no criadero comercial. Páginas armadas con bloques ACF (mismo flujo que Amerilist).

## Ver el diseño ahora

Abre `preview.html` en el navegador.

## Marca

**Stony Point Doodles**  
*Healthy Puppies. Loving Homes. Lifelong Friends.*

Navegación: Home · Our Puppies · Upcoming Litters · Meet Our Dogs · Our Story · Puppy Application · FAQs · Contact  
Botón destacado: **Apply for a Puppy**

## Edición

1. ACF PRO + tema **Stony Point Doodles** (`wordpress/wp-content/themes/haven-ridge/`)
2. Apariencia → Stony Point setup
3. Pega la URL del Google Form en **Site settings → Puppy application**
4. Home se arma con bloques de la categoría Stony Point

Fotos de Mila, Nico, Remy, Chai, Lulu, Zoe y la camada actual se suben en cada bloque o en los CPTs Puppies / Puppy parents.
